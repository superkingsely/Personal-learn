
## software enginering concept | software architecture and design concept

2. The major categories you should know
1. Software Architecture

How you organize the overall application.

It determines the major components, their responsibilities and how they communicate.

Examples:
- Clean Architecture
- Vertical Slice Architecture
- Layered Architecture (N-tier)
- Hexagonal Architecture (Ports and Adapters)
- Microservices Architecture
- Modular Monolith


2. Design Patterns

Reusable solutions to common software design problems.

Examples:
- Repository Pattern
- Factory Pattern
- Adapter Pattern
- Strategy Pattern
- Observer Pattern
- Singleton Pattern
- Decorator Pattern
- Mediator Pattern


3. Design Principles

Guidelines that help you write maintainable and flexible code.

Examples:
- SOLID principles
- DRY (Don't Repeat Yourself)
- KISS (Keep It Simple, Stupid)
- YAGNI (You Aren't Gonna Need It)
- Separation of Concerns
- Encapsulation


4. Architectural Patterns / Styles

Established ways of structuring and organizing systems.

Examples:
- Event-Driven Architecture
- CQRS
- Event Sourcing
- Client-Server
- Pipe and Filter
- MVC (Model-View-Controller)
Note: Some of these are also described as architectural styles, application patterns or design patterns depending on their scope.


5. Development Practices

How you approach building and maintaining software.

Examples:
- Test-Driven Development (TDD)
- Continuous Integration (CI)
- Continuous Deployment (CD)
- Code Reviews
- Refactoring
- Unit Testing
